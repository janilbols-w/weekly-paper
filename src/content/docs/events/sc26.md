## 精选论文

### 1. [Pushing the Envelope of LLM Inference with Ultra-Low-Bit Quantized Models](https://arxiv.org/abs/2508.06753)

**61/100 · LLM 高效推理 > 模型与算法效率 > 量化与低精度 · Sparse and Low-Precision AI Kernels**

论文从 2-bit CPU microkernel 出发，把同一低比特执行路径扩展到 Intel Xe2 GPU，并接入 vLLM；重点不是再提出一种量化算法，而是让已经训练好的超低比特模型真正获得端到端运行时收益。

**为什么值得关注：** 作者在所测 CPU 上报告相对 bitnet.cpp 最高 2.2×，相对 16-bit 推理最高 7×；Xe2 GPU 上的 vLLM pipeline 相对 16-bit 最高 6.7×。这说明低比特权重只有与 ISA、packing、microkernel 和 serving runtime 联合设计，才会转化为真实吞吐与延迟收益。

**边界：** 结论绑定于作者使用的 2-bit checkpoint、Intel CPU/Xe2 GPU 与特定 shape；论文摘要没有给出所有模型的任务质量差异，也不能把峰值加速外推到 NVIDIA/AMD GPU 或任意后训练量化模型。

[PDF](https://arxiv.org/pdf/2508.06753)

### 2. [MIST: A Co-Design Framework for Heterogeneous, Multi-Stage LLM Inference](https://arxiv.org/abs/2504.09775)

**58/100 · LLM 高效推理 > 运行时与内存效率 > Attention 与 KV Cache · Resource-Aware LLM Serving Pipelines**

MIST 用事件驱动模拟统一描述 RAG、KV retrieval、reasoning、prefill 与 decode，并允许把不同阶段映射到 AMD GPU、TPU 或自定义 accelerator，以替代穷举真实部署的昂贵试验。

**为什么值得关注：** 官方摘要报告对真实部署的端到端误差在 6% 以内；在论文设定的定价与硬件假设下，跨厂商 PD 解耦方案最高提高 49.3% tokens/$。它把 serving 配置选择从经验调参推进为 workload、内存层级、网络与成本的联合探索。

**边界：** MIST 的结论依赖输入 trace、硬件模型、价格与网络假设；模拟 fidelity 不等于新硬件和生产流量上的实测保证。峰值 tokens/$ 也不能脱离论文的供应商、SLO 与 KV storage 条件使用。

[PDF](https://arxiv.org/pdf/2504.09775) · [代码](https://github.com/MIST-Simulator/MIST)

### 3. [ZOCheck: CPU-Shadow Checkpointing for Zeroth-Order LLM Fine-Tuning](https://arxiv.org/abs/2609.27189)

**56/100 · AI 基础设施 > 训练与数据中心基础设施 > 分布式训练与 Checkpoint · LLM Systems: Inference, Agents, and HPC Operations**

ZOCheck 利用 zeroth-order 优化只需 seed 与 scalar step log 即可重放的结构，让 CPU shadow 持续追赶 GPU 训练并异步生成一致恢复镜像，把 checkpoint 移出 GPU critical path。

**为什么值得关注：** 作者报告 checkpoint overhead 最高降低 219.7×、平均 recovery latency 降低 1.55×，在评估的故障率下端到端 wasted time 最高降低 21.3×，同时保持与原执行轨迹一致的恢复状态。

**边界：** 方法专门利用 ZO 更新的可重放性，不能直接套用到保存 optimizer/gradient state 的常规一阶训练；CPU shadow 必须能跟上 GPU 更新速率，收益也依赖故障率、快照策略、主机资源和持久化带宽。

[PDF](https://arxiv.org/pdf/2609.27189)

### 4. [HieraSparse: Hierarchical Semi-Structured Sparse KV Attention](https://arxiv.org/abs/2604.16864)

**55/100 · LLM 高效推理 > 模型与算法效率 > 压缩 稀疏化与蒸馏 · Sparse and Low-Precision AI Kernels**

HieraSparse 用 block-level 与 element-level 两级稀疏组织 KV Cache，并把 K/V 转置为稀疏 Tensor Core 可直接消费的操作数；专用 prefill/decode kernel 避免把压缩后的 KV 先解压回 dense。

**为什么值得关注：** 论文在相同稀疏度下报告相对 unstructured decode 方法 1.2× KV 压缩率和 4.57× attention 加速；使用简单 magnitude pruning 时，prefill/decode 分别获得 1.37×/1.77× 加速且质量下降不显著。代码公开并提供 L40S 预调 kernel。

**边界：** 公开实现当前预调目标是 L40S、CUDA 12.8 与特定 Llama attention shape；质量结论来自简单 pruning 和有限任务。扩展到其他 GPU 需要重新调优，细粒度动态稀疏与量化组合仍是后续工作。

[PDF](https://arxiv.org/pdf/2604.16864) · [代码](https://github.com/psl-ntu/HieraSparse)

### 5. [BidKV: Utility-Guided Preemption Scheduling for KV-Pressure LLM Serving](https://sc26.conference-program.com/presentation/?id=pap1108&sess=sess210)

**53/100 · AI 基础设施 > 推理服务平台 > Serving Engine 与运行时 · Resource-Aware LLM Serving Pipelines**

BidKV 把 KV Cache 不足时的 victim selection 建模为 utility ranking：同时考虑可释放容量与请求被打断的代价，再复用 vLLM/SGLang 原生 preemption 机制执行回收。

**为什么值得关注：** 在 Llama-3.1-8B-Instruct 与 ShareGPT trace 上，官方摘要报告 vLLM 的 P95 TTFT 降幅超过 90%，300ms SLO 达标率提高 14.8 个百分点；SGLang 上相对原生 LRU 的达标率提高 38.8 个百分点。公开 artifact 表明策略可作为轻量适配层接入两类引擎。

**边界：** 当前公开实现与论文评估集中在单模型、单类 trace 和有限 GPU 配置；artifact 还记录了吞吐与尾延迟之间的权衡。跨模型、多租户和多 NPU 结论仍需独立实验，仓库已归档为只读。

[代码](https://github.com/vLLM-HUST/vllm-ascend-hust-bidkv)

### 6. [Prefill-Decode Aggregation or Disaggregation? Unifying Both for Goodput-Optimized LLM Serving](https://arxiv.org/abs/2508.01989)

**51/100 · LLM 高效推理 > Serving 与分布式推理 > Prefill-Decode 解耦 · Papers in Conversation: AI Inference Becomes an HPC Systems Problem**

TaiChi 不把 PD 聚合与解耦当成二选一，而是用 prefill-heavy/decode-heavy 实例、flowing decode 和 length-aware prefill 调度，在请求之间重新分配 TTFT/TPOT 的 SLO slack。

**为什么值得关注：** SC26 官方版本报告相对现有聚合/解耦方案 goodput 最高提高 40%，P90 TTFT/TPOT 最高降低 5.3×/1.6×；作者版更完整的 workload sweep 显示收益随 SLO 组合显著变化，核心价值是明确何时聚合、何时解耦、何时混合。

**边界：** 收益依赖可预测的输入/输出长度、GPU 角色比例、chunk size、网络和 SLO 分布；论文也把动态调整实例比例与输出长度预测列为后续工作。不能把特定 Qwen/ShareGPT/摘要 workload 的峰值外推到任意线上流量。

[PDF](https://arxiv.org/pdf/2508.01989)
