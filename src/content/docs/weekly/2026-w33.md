## 本周精选

### [LLMVisor: A Real-Time Latency Attribution Model for Multi-Tenant LLM Serving](../../papers/arxiv-2608.08382/)

**53/100 · AI 基础设施 > 服务平台 > Serving Engine 与 Runtime**

### [Optimizing CUDA like a Human: Micro-Profiling Tools as Expert Surrogates for LLM-Based GPU Kernel Optimization](../../papers/arxiv-2606.26453/)

**56/100 · LLM 高效推理 > Runtime 与内存效率 > Kernel 与算子融合**

### [StitchCUDA: An Automated Multi-Agents End-to-End GPU Programing Framework with Rubric-based Agentic Reinforcement Learning](../../papers/arxiv-2603.02637/)

**55/100 · LLM 高效推理 > Runtime 与内存效率 > Kernel 与算子融合**

StitchCUDA 以 Planner、Coder 和 Verifier 协作生成端到端 GPU 程序，并用真实执行反馈与 rubric 奖励训练 Coder，覆盖主机侧设置、内核融合和 cuBLAS epilogue 等优化。

### [High-Layer Attention Pruning with Rescaling](../../papers/arxiv-2507.01900/)

**54/100 · LLM 高效推理 > 模型与算法效率 > 压缩、稀疏与蒸馏**

提出免训练的高层注意力头剪枝方法 HARP，优先移除网络高层的注意力头，并用自适应缩放校正剪枝后 token 表征幅度；实验覆盖 4 个 LLM 和 27 个生成、判别数据集。

### [FronTalk: Benchmarking Front-End Development as Conversational Code Generation with Multi-Modal Feedback](../../papers/arxiv-2601.04203/)

**53/100 · LLM 高效推理 > Runtime 与内存效率 > 编译器与计算图优化**

FronTalk 收集 100 组真实网站衍生的多轮前端开发对话，为每轮提供等价的文本与视觉指令，并以 Web Agent 同时评估功能和体验；20 个模型的测试暴露了遗忘与视觉反馈理解问题。
