## 采集范围

核心来源为 arXiv Atom API、arXiv 官方分类 RSS、OpenReview 和目标会议官方页面；OpenAlex 可作为带 key 的 arXiv 索引增强源。研究机构博客及科技媒体只作为发现线索，最终条目必须能回溯到论文或官方 Artifact。

工作日逐日收集 arXiv RSS，周五再用 Atom API 补齐整周窗口。RSS 中的日期表示本次 arXiv 公告日，因此更新版本也可能出现在当周页面。

## 三级分类

每篇论文有一个主分类用于统计：一级领域 → 二级方向 → 三级技术路径。跨领域内容保存在辅助标签中，不重复计数。

## 评分

| 维度 | 满分 |
|---|---:|
| 主题相关性 | 25 |
| 技术新颖性 | 15 |
| 实验严谨性 | 20 |
| 实际价值 | 20 |
| 可复现性 | 10 |
| 可信度信号 | 10 |

初筛评分来自标题、摘要和可验证元数据；进入候选集后，才定向读取论文的实验设置、关键结果、表格和限制。页面上的 `reading_depth` 明确标注判断深度。

当前规则初筛的归档线为 38，精选候选线为 45。LLM 编辑增强会按同一六维量表重新评分，因此增强后的分数可覆盖完整 0–100 区间。

## 质量保护

- 性能数字必须结合硬件、模型、精度、Batch 和序列长度理解。
- 新论文不因引用数低而扣分。
- 没有达到精选质量线时不会强行凑满 5 篇。
- 正式推送要求中文摘要和“为什么值得关注”字段完整。
