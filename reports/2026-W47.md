## 本周精选

### 1. [LEDGE: An Efficient Simulator for Distributed LLM Serving on Heterogeneous Edge Devices](https://arxiv.org/abs/2611.24085)

- **分类**：Serving Engine 与 Runtime
- **评分**：56/100
- **摘要**：LEDGE 用离散事件图模拟异构边缘设备上的分布式 LLM 服务，覆盖非均匀张量并行、流水线并行与共享链路争用，并以端到端测量校准可复用的性能模型。
- **为什么值得关注**：它把模型切分、设备放置和网络拓扑的组合搜索从昂贵的实机试验转为快速仿真，有助于在资源受限的边缘集群中比较延迟与扩展性方案。
- **主要限制**：性能模型仍需实机测量校准；实验集中于 10 台 Jetson 与树莓派设备及有限的模型—精度组合，迁移到其他硬件、网络和负载形态时仍需验证。
- **代码**：https://github.com/gdfwj/LEDGE

### 2. [SharQ: Bridging Activation Sparsity and FP4 Quantization for LLM Inference](https://arxiv.org/abs/2606.26587)

- **分类**：量化与低精度
- **评分**：59/100
- **摘要**：SharQ 以在线稀疏—稠密分解处理激活：将离群值为主的 N:M 稀疏骨干量化为 FP4，再用稠密 FP4 残差同时补偿掩码损失与稀疏路径量化误差，并融合准备阶段算子。
- **为什么值得关注**：该方法无需校准数据、重训练或模型专用调参，尝试把现代加速器已有的半结构化稀疏与 FP4 能力组合起来，直接改善推理延迟和吞吐。
- **主要限制**：性能结果主要来自 RTX 5090 与文中选定的模型和低精度格式；双路径 GEMM、融合算子及稀疏 FP4 支持对硬件和运行时有明确依赖，跨平台收益仍待验证。
- **代码**：https://github.com/actypedef/SharQ

### 3. [RoCoKV: Accelerating LLM Inference Serving through Uncertainty and Redundancy Aware KV Cache Compression](http://arxiv.org/abs/2611.25433v1)

- **分类**：Attention 与 KV Cache
- **评分**：55/100
- **摘要**：RoCoKV 针对长推理轨迹，按模型不确定性动态调整 KV 缓存裁剪强度，并降低近期重复内容的保留优先级；同时以融合 CUDA 解码内核接入 vLLM 的分页 KV 与 CUDA Graph 路径。
- **为什么值得关注**：它把压缩策略与服务栈联合设计，目标是在受限 KV 预算下兼顾推理准确率、吞吐与端到端加速，尤其适合生成阶段占主导的推理模型。
- **主要限制**：实验覆盖 3 个推理基准和 2 个模型，摘要中的服务性能重点来自一个 8B 模型；对更大模型、不同任务分布及其他推理引擎的泛化尚未建立。
